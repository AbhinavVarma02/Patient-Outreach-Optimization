| ID | Work | Exit criterion |
| --- | --- | --- |
| M0 | Source intake and portable handoff | Original hashes match, v1.0 preserved, canonical files and Git in place |

| M2 | Replication and plan | Analysis plan locked before outcome access, published contrasts replicated within tolerance |

| M6 | Trial document intelligence | Typed provenance, deterministic checks, abstention and measured held-out evaluation |
| M7 | Decision workspace | Responsive targeting, planner, pilot and evidence views with approved inputs |
| M8 | Release audit | Claim, privacy, browser, accessibility, dependency and cost checks on final build |
| M9 | GitHub and Cloudflare | Intended account verified, safe GitHub publication and verified free Pages deployment |
| M10 | Portfolio handoff | Technical guide, results and limitations, reproducible artifacts and verified release metadata |
