# Milestones and acceptance

| ID | Work | Exit criterion |
| --- | --- | --- |
| M0 | Source intake and portable handoff | Original hashes match, v1.0 preserved, canonical files and Git in place |
| M1 | Data, literature, rights and study design | Live file and hash verification, documented permissions, reviewed estimands and comparability |
| M2 | Replication and plan | Analysis plan locked before outcome access, published contrasts replicated within tolerance |
| M3 | Statistical toolkit | Known-answer tests, simulation calibration, independent checks and documented assumptions |
| M4 | Policy evaluation | Matched-capacity baselines and learned policies, independent evaluation and honest uncertainty |
| M5 | Transfer and channel economics | Within-design channel contrasts, comparable frozen temporal policy if identifiable |
| M6 | Trial document intelligence | Typed provenance, deterministic checks, abstention and measured held-out evaluation |
| M7 | Decision workspace | Responsive targeting, planner, pilot and evidence views with approved inputs |
| M8 | Release audit | Claim, privacy, browser, accessibility, dependency and cost checks on final build |
| M9 | GitHub and Cloudflare | Intended account verified, safe GitHub publication and verified free Pages deployment |
| M10 | Portfolio handoff | Technical guide, results and limitations, reproducible artifacts and verified release metadata |

M1 rights and M2 replication gate row-level causal research. M3 and M7 may proceed using fictional inputs and explicitly cited, published aggregate results. M9 requires a passing release audit and authenticated account access. A limited release cannot close outstanding real-data milestones.
