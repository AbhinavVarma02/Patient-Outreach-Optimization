# Document extraction holdout protocol

The 30 trials and 35 checks frozen for the original benchmark are development evidence for this iteration. Their manifest, outputs and original acceptance threshold remain intact. Development inspected PDF text, error families and benchmark scores before the new holdout was scored.

The final page-conditioned evaluation uses 30 disjoint ClinicalTrials.gov protocols on screening, vaccination uptake and smoking cessation. Independent here means disjoint source trials, with one annotator and a common public registry. The registry PDF source dates, content digests, physical page locators and labels are frozen. Registry search and scope review selected protocol design and endpoint pages. A supplied text-free page, multiple assignment units in scope, absent information or a non-duration endpoint warrants abstention. No OCR or whole-document retrieval claim is supported. Evidence is independently labeled with a short semantic anchor on the relevant page. An output needs the expected value and a supporting span that contains or is contained by that anchor. Registry output has a structured pointer and must independently agree with the protocol reference value. Report annotator and anchor limitations.

Compare structured registry, deterministic extraction from plain reading order and layout-preserving text, and Qwen2.5 7B with and without deterministic corroboration. Llama 3.2 3B is a development comparator. These choices use the disjoint original trial results and installed model availability. Pin local model digests with the extractor and lock pypdf to 7.1.1. Score schema validity, exact match among scorable checks, coverage, correct abstention, incorrect and unsupported populated fields, and median and maximum wall time. Record model file size, quantization and token counts. Model time includes the local API request and model load when it occurs. PDF modes include selected-page preprocessing. Report timing scope and hardware limitations. No public or paid model endpoint is permitted.

The original acceptance criterion remains at least 90% exact match on scorable fields and zero populated abstention cases. Keep reviewed source summaries as the production path unless model assistance clears the gate and its evidence can be reviewed. No changes to extractors, labels or acceptance criteria after viewing holdout outputs unless a separate, untouched successor holdout is created for the next quality claim.

## Final bounded cycle

Reuse the original case set for development and the earlier independent set as prior evidence. Compare the existing deterministic parser with a revision that expands assignment-unit vocabulary and assignment syntax and recognizes written-out endpoint durations. Keep full-page conflict checks and require the local model's numbered source span to agree with the deterministic parser. Use the installed Qwen2.5 7B checkpoint. Compare value, evidence alignment, structured conformance, abstention and runtime. Count whether the top 12 excerpts contain a manually reviewed anchor on scorable fields. This measures retrieval within supplied pages. It leaves full-document retrieval and OCR unvalidated.

Select new trials using the ClinicalTrials.gov v2 query in the final manifest. Use trials absent from both earlier manifests. Use only public protocol PDFs with an official locator, and retain text-poor and ambiguous cases in the chosen set. Review assignment unit on each trial and endpoint duration on the first six trials by NCT identifier. Freeze exact PDFs, registry snapshots, physical pages and answer labels before scoring. The original threshold remains in force. Evidence alignment and gain over the deterministic path are additional requirements for automation. Finish after one holdout run. Preserve earlier results, including failures.
