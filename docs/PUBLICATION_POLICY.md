# Publication policy

The release includes original static software, attributed published evidence, reviewed Haryana and Sierra Leone community aggregates, trial extraction evaluation metrics and fictional planning inputs. The project license excludes the OSF datasets and original third-party attachments. Files in data, research/source-inputs, artifacts/private, .cache and web/qa-output remain ignored. Published materials omit participant records, split membership, fitted model weights and inferred identifiers.

Run npm run build and npm run release:check in web before deploying. The build scanner accepts only the generated entry page, hashed JS and CSS, favicon and security header file. It rejects unexpected files, outbound endpoints outside the cited documentation set, obvious credentials, raw dataset markers and source-map references. Inspect source and tracked files separately. Upload only web/dist.

Derived aggregates require documented reporting rights, review, a cell threshold of 11 or stricter, and complementary suppression and reconstruction checks across tables. The Haryana release exposes only full-domain regression contrasts and whole-holdout summaries. It omits geography, split membership, demographic combinations, small bundle counts, scores and fitted parameters. The projection test and build allowlist enforce the shipped schema. The scanner alone cannot certify disclosure risk.

The Sierra Leone web projection exposes full study effects, overall denominator counts and four whole-holdout contrasts. Every published policy arm has 20 or more villages. There are no cross-tabulations or related small cells in the static release. Structure diagnostics report no exact counts below the minimum cell threshold. Trial benchmark case rows are public document annotations. Neither protocol PDFs nor model weights ship in the web build.
