# Publication policy

The release is an original static application and published source citations with fictional planning inputs. The project license excludes the OSF datasets and original third-party attachments. Files in data, research/source-inputs, artifacts/private and web/qa-output remain ignored. Published materials contain no field-level records or inferred identifiers.

Run npm run build and npm run release:check in web before deploying. The build scanner accepts only the generated entry page, hashed JS and CSS, favicon and security header file. It rejects unexpected files, outbound endpoints outside the cited documentation set, obvious credentials, raw dataset markers and source-map references. Inspect source and tracked files separately. Upload only web/dist.

Future derived aggregates require documented reporting rights, independent review, cell threshold of 11 or stricter, complementary suppression and reconstruction review across all published tables. The scanner cannot certify these statistical privacy properties.
