# Pre-analysis protocol v1

Recorded 2026-11-24 before any project access to row-level outcomes. Prior findings are known. The supplied review discloses Study 2 arm aggregates, pooled contrasts and oracle power. The authors' supplement reports population overlap, Study 4 arm comparisons and sensitivity work. This is a repository-stamped analysis plan. It has no external registration.

## Estimands and decision sequence

- RQ0 is a gate. Reproduce each authors' primary analysis set, assigned-arm contrast, outcome window and estimator. Compare absolute risk differences against published values with a 0.1 pp tolerance after accounting for rounding. Resolve discrepancies before outcome access for downstream code. Show arm counts, denominator changes and intervals. For all randomized people, use observed outcomes where defined and report missing-outcome bounds where needed. Use shared-address exclusion as sensitivity only.
- RQ1 primary family is pooled risk disclosure against passive control by the top 3% versus 4–10% risk groups in each of Studies 1 and 2. Test the within-trial difference in assigned-arm risk differences with two-sided tests and Holm correction at family alpha 0.05. Show both trial-specific intervals. Document risk flags, exclusions and known probabilities before analysis. RQ1 comparisons with Study 3's 11–20% are descriptive because risk strata and trial conditions vary together.
- RQ2 secondary and exploratory. Compare uniform allocation, clinical band, control-arm behavioral risk, intermediate behavioral risk, simple subgroup rules and any trained effect rule at matched 20% and 50% capacity. 10% is sensitivity. All comparator thresholds and tie-breaking rules must be frozen. Prefer independent evaluation for each fitted policy. Reusing a test set to select a winner invalidates ordinary pointwise confidence intervals for that winner. Independently validate any cross-fit policy variance estimator before using it.
- RQ3 is conditional on matching actions, endpoints, feature semantics, and dependence assumptions. Freeze preprocessing and policies in earlier trials and evaluate later with study-specific known assignment probabilities. Report overlap restrictions and cross-season uncertainty without linkage. Avoid test-outcome access during selection.
- RQ4 uses Study 4's experimentally supported assigned-modality contrasts within the primary full-contact-eligibility stratum. Use the prespecified 29-day vaccination outcome and add Holm-adjusted intervals or tests for additional comparisons. Treat joint arms as bundles. No inferred effect for an unrandomized bundle.
- RQ5 uses a prospective participant-randomized policy-vs-policy design. Compare uniform outreach and a frozen targeting rule at identical capacity. Report assumptions on average and concentrated benefit, ranking quality, baseline risk, allocation, clustering, attrition, and independent evaluation. Evaluate a separate retrospective oracle design before offering it as a separate calculator.

Only pre-treatment features with verified semantics enter training. Clinical risk, behavioral risk, benefit and contactability have different meanings. Keep race and ethnicity out of the primary policy. Require at least 11 observations in every released subgroup-arm cell plus complementary suppression and reconstruction review. Report unassessed groups. No inference or linkage begins until permission is documented.

## Limited software validation

Fictional independent randomized replicates will test known-answer formulas and interval behavior at 1,000 or more repetitions per scenario. Use nominal 95% intervals, a Wilson Monte Carlo confidence interval and the review's 93–97% operating band for the coverage point estimate. For the size check, report the observed null rejection rate and whether its Wilson interval includes 5%. Record bias and policy regret. Missing, clustered or incompatible data fail closed unless a suitable estimator has been independently validated.
