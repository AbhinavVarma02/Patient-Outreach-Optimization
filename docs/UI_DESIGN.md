# UI design

An ivory workspace frames a deep green research overview with an illustrative risk-band chart. The masthead holds navigation and theme selection. Task pages place assumptions next to outputs and stack them on narrow screens. Tables repeat chart values, keyboard users can skip to content, and focus moves to the main landmark after route navigation.

Georgia and local system sans fonts provide the type hierarchy without font downloads. Output units distinguish percentages, percentage points and expected counts. The scenario status is visible in each decision view. Control and layout checks are in web/tests/workspace.spec.ts.
