# Cost model

The project uses local CPU, installed local inference, open-source dependencies, an existing GitHub account and the existing Cloudflare account. The public build is a five-file static deployment without Pages Functions, Workers compute, databases, storage add-ons, custom domains or paid model requests. Local hardware and electricity are resources. No billing change is required.

Cloudflare lists 500 monthly Git-triggered builds, 20,000 files per Free site and a 25 MiB per-file limit. Direct Upload has its own file and project constraints. Release only through free static Pages and stop if an operation requires a paid service. [Cloudflare Pages Free limits](https://developers.cloudflare.com/pages/platform/limits/) · [Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)
