# Operations runbook

The public release is static. If a workflow stops working, record the production version and affected route, rerun the build and publication verifier, and reproduce the issue with the browser matrix. Use Pages rollback to a previously tested deployment if a release is responsible. Capture actual headers, failed requests and calculator evidence. Record corrective actions in progress.md and PROJECT_STATE.json.

If rights or evidence changes, update the research protocol and document permission evidence without posting confidential correspondence. Review all gates before publishing new findings. See [Deployment](DEPLOYMENT.md) and [Publication policy](PUBLICATION_POLICY.md).
